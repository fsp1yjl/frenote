# 指板手记 · CAGED 指板知识

一个专注于 CAGED 和弦推导与指板知识的本地 Web 应用。这是完整应用的裁切版本，不包含学习档案、笔记、打卡或数据导入导出。

## 功能

- 12 个调的大三、小三、大七、属七与小七和弦推导
- CAGED 五种指型的根音定位、公式与实际音名
- 当前指型的标准左手按法图，包含手指编号、空弦、闷弦与横按
- 可交互的标准调弦指板
- 离线 PWA 支持

## 运行

不需要安装依赖。在项目目录启动任意静态文件服务器：

```bash
python3 -m http.server 8000
```

然后访问 <http://localhost:8000>。

应用不保存练习内容，也不请求登录或上传数据。

## 指型约定

公式中的 `1`、`b3`、`3`、`5`、`b7`、`7` 分别表示根音、小三度、大三度、纯五度、小七度与大七度。指板纵向按一弦在上、六弦在下排列，使用标准调弦 `E A D G B E`。

## 扩展和弦类型

在 `app.js` 的 `CHORD_TYPES` 中加入新的音程数组与级数公式，例如减七和弦可以使用：

```js
dim7: {
  id: "dim7",
  label: "减七和弦",
  short: "减七",
  suffix: "dim7",
  intervals: [0, 3, 6, 9],
  formula: ["1", "b3", "b5", "bb7"],
  description: "由堆叠小三度组成，具有强烈的不稳定感。"
}
```

再把类型 ID 加入 `CHORD_TYPE_ORDER`，和弦选择器、音名推导、CAGED 指型和左手按法会自动接入。若引入 `b5`、`bb7` 等当前尚未使用的级数，还需要在 `TONE_CLASS`、`TONE_LABEL`、`INTERVAL_LABEL` 与 `DEGREE_LETTER_STEPS` 中补充显示和拼写规则。
